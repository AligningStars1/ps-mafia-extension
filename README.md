🕵️ PS-Mafia ISO, Search & Multi-Quote Extension
A powerful, all-in-one companion Chrome extension custom-built for ps-mafia.proboards.com. Designed specifically for Mafia players and hosts, this tool restores essential forum features, streamlines player isolation (ISO) views, manages multi-quotes with precise BBCode formatting, tracks game days, provides a built-in folder-based note-taking system, and keeps threads live without manual reloads.

🌟 Key Features & What It Does

Automatic Background Thread Scanning:
The moment you open any forum thread, the extension silently scans and caches all pages in the background with a live whole-integer percentage progress counter.
Completed pages are cached locally in IndexedDB, making subsequent visits instantaneous.

Player ISO (Isolate) & Keyword Search:

Select any player from the dropdown to view all of their posts in one clean popup modal.
Filter ISO results or search queries by specific game days (Day 1, Day 2, etc.).
Fast keyword search pre-computes matches so filtering is instantaneous.
Direct post jump links take you right to the exact page and post (Page X (#Y) ↗).

Multi-Quote Queue & BBCode Formatting:
Click + Multi-Quote on any post to add it to your persistent queue.
Insert in Reply or Copy BBCode automatically formats quotes with authentic ProBoards handles (e.g., @dragoniteplayzyt) and correct source URLs.
Includes a "Strip nested quotes" toggle to clean up message clutter.

Live Thread Refresh (♻️):
Click the bottom-left refresh button to fetch new posts in the background without losing your thread scan progress or reloading the tab.
New posts are highlighted in green, scrolled into view, and instantly equipped with ISO and Multi-Quote buttons.

Game Day Tracking & Badges:
Automatically detects host announcements formatted as [code]Day X[/code] while intelligently ignoring player quotes and preventing day rollbacks.
Displays a Day X badge at the top right of every post and ISO result card.

Folder-Based Note-Taking System:
Access notes via the bottom-left sticky note icon.
Outside threads, view all folders, create custom folders, and edit/delete notes.
Inside a thread, it automatically opens or creates a folder matching the thread title, allowing you to jot down reads and commentary on the fly.

Feature Options Menu:
Click the Orangutan extension icon in your Chrome toolbar and select Options to toggle individual features (Search, ISO, Multi-Quote, Notes, Live Refresh, Day Filters) on or off instantly.

⚙️ How to Disable Options

If you ever want to turn off specific features:
Click the Orangutan icon in your Chrome extensions toolbar.
Click the ⚙️ Options button.
Uncheck any feature you wish to disable (e.g., Multi-Quote, Notes, Live Refresh). Changes apply immediately without restarting your browser.

🚀 Installation Instructions

Download the latest proboards-search-extension-v29.zip release by going on to <> Code and download zip.

Extract/unzip the file into a folder on your computer.

Open Google Chrome and navigate to chrome://extensions/.

Enable Developer mode using the toggle in the top-right corner.

Click Load unpacked and select your extracted extension folder.
